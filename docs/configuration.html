Settings for the server

Almost everything is set in the app, in Settings. The container takes a few environment variables, all optional — the configurator sets the ones your setup needs.

VariableDefaultWhat it does
PORT3390The port the web app, the wall display and the Android app use.
LMS_HOST(found on the network)Lyrion's address. Needed when the server runs on another machine or network than Lyrion: finding it by itself works only on the same network.
LMS_PORT9000Lyrion's web port.
LMS_USER / LMS_PASS–Lyrion's username and password, if you set one.
MUSIC_DIR/musicWhere the optional read-only music folder is mounted inside the container: tracks kept ahead on the phone, and record-label tags.
TS_AUTHKEY–Joins the built-in Tailscale to your tailnet without signing in in a browser.
TS_HOSTNAMEmusicd-lmsThe server's name on your tailnet.
TAILSCALEonoff leaves the built-in Tailscale out (if Tailscale runs on the host instead).
SLIMPROTO_PORT3483Lyrion's player port, for the phones' own players, if you moved it.
LOG_LEVELinfoerror, warn, info, debug or trace. DEBUG=1 is the same as debug.
LOG_FILEdata/logs/musicd.logThe rotating log file kept beside docker logs (8 MB × 10). off to switch it off.

Free API keys

All free and optional. They add what Lyrion doesn't have.

FanArt.tv — record-label logos

  1. Get a keySign in at fanart.tv/get-an-api-key and request a personal API key.
  2. Paste itSettings → Artwork & metadata → FanArt.tv key → Save.

Discogs — label names and logos the others miss

  1. Get a tokenSign in at discogs.com → Settings → Developers → Generate new token.
  2. Paste itSettings → Artwork & metadata → Discogs token → Save.

YouTube Data API v3 — music videos on the wall display

  1. Make a projectAt console.cloud.google.com, with any Google account: New project, any name. No billing account is needed.
  2. Switch the API onAPIs & Services → Library → YouTube Data API v3 → Enable.
  3. Make a keyAPIs & Services → Credentials → Create credentials → API key. Best restricted to YouTube Data API v3 only.
  4. Paste itSettings → Wall display → YouTube API key → Save.

The free quota (10,000 units a day) covers a home display comfortably — about ninety new tracks a day, and results are kept. If it ever runs out, videos pause until midnight Pacific time.
