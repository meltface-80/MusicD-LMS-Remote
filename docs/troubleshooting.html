Troubleshooting

Symptom by symptom. Not here? Send the log.

The app can't find Lyrion

Set LMS_HOST to Lyrion's address (and LMS_PORT if it isn't 9000): finding Lyrion by itself works only on the same network, and not from Docker's bridge network. Settings → LMS server can change it without restarting.

Mallard doesn't find the server

Type its address in Mallard, e.g. 192.168.1.20:3390. Phone and server must be on the same network at home; away, sign both in to Tailscale.

Nothing plays on This phone

Update both the server and Mallard to the same release. Still silent? Switch on the diagnostic log, play something, and send it: it shows each track handed to the phone and what its player did.

Tracks aren't kept ahead

Mount your music folder into the container (how). Qobuz and TIDAL tracks are held one ahead only.

My Qobuz albums aren't in the Library

Settings → LMS server says why: usually Lyrion's Online Music Library is off, or its Qobuz switch is, or the albums were browsed but not favourited.

Saving a playlist fails

Lyrion needs a Playlists folder it can write to: Lyrion's Settings → Basic Settings.

The wall display is blank

Switch it on in Settings → Wall display, and choose a player for it to follow.
