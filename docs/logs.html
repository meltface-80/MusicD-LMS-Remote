Logs and reporting a problem

A report with what you did, what happened, and the diagnostic log from that moment is usually enough to fix it. Open an issue on GitHub and attach the log.

The diagnostic log

Off unless you switch it on. If something isn't working:

  1. Switch it on — Settings → System → Diagnostic logging, in the Android app or the web app (it is one switch, for the server and both apps).
  2. Use the app until the problem happens. While it is on, the server logs in detail and writes a snapshot of what it holds every five minutes; the Android app sends it what it does — screens, taps, every request with its time, playback, errors and crashes — under the phone's name, and the web app its errors.
  3. Download it — Settings → System → Log → Download. The Android app saves it to the phone's Downloads/Mallard folder (Android 8 and 9 ask where); the web app downloads it in the browser.
  4. Switch it off again once you have it.

It is one text file: a header (the versions, Lyrion, your players, and when Lyrion last stopped answering), the server's own log, Lyrion's own server.log and scanner.log, and from the Android app the phone's own recent lines. Passwords, keys, email addresses, and internet and Tailscale addresses are left out of every line; your home network's addresses, room names and what was playing are kept, because they are what a problem is found by. Read it before you send it.

The server's log, from Docker

docker logs --since 30m musicd-lms-remote

The same lines are kept in a rotating file in the data volume, logs/musicd.log; set LOG_LEVEL=debug on the container for more detail without the switch.

When Lyrion stops answering

The server notes every time Lyrion stops answering and comes back — how long it was gone, and what the server was asking it at that moment. It is in the diagnostic log's header, and at http://<server>:3390/api/lms/outages.

What to include

  • What you did and what you expected, and when (the time helps find the lines).
  • The diagnostic log, and a screenshot if it's something you see.
