Install the server

The server runs in Docker and talks to Lyrion Music Server over the network (HTTP on Lyrion's web port, 9000 unless you changed it). It does not have to run on the same machine as Lyrion. Pick where it runs, fill in the details, and copy the command.

The address of the machine running Lyrion Music Server.
The port you'll open in your browser.

          

          

          
Nothing to clone or build — the image is published to the GitHub
             Container Registry (ghcr.io/meltface-80/musicd-lms-remote) with every
             release, for x86-64, 64-bit ARM and 32-bit ARM. Needs Docker 20.10 or later. You can
             also change the LMS host/port later from the in-app Settings screen instead of
             the environment variables.

Your music folder (optional)

  
If the machine running the server can see your music files, mount them read-only into the container — the configurator's
     Mount local music library does it, or add this to docker run:

  
-v /path/to/your/music:/music:ro

  
Mallard then keeps the next tracks of your own music on the phone ahead of time, read straight from the folder, and the
     record-label scan reads each file's LABEL tag. Use the folder Lyrion scans. If it lives somewhere other
     than /music inside the container, set MUSIC_DIR to match.

  
Updating

  
Settings → System offers each new release in the app, one tap. Or pull the newest image and recreate the container
     with the same command — with Compose, docker compose up -d fetches it by itself
     (pull_policy: always). Everything the app keeps — settings, favourites, play history, caches, the
     server's Tailscale identity — lives in the musicd-lms-remote-data volume and carries over. Mallard
     offers its own updates on its Home screen and in Settings → System.
