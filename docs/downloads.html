Downloads

Two pieces: the server, which runs in Docker beside Lyrion Music Server, and Mallard, the Android app. The web app and the wall display come with the server — open it in any browser.

🐳 The server · v1.0.87

A Docker image for x86-64, 64-bit ARM and 32-bit ARM (a Raspberry Pi). Docker 20.10 or later. Nothing to clone or build: the install page writes the command for your setup.

ghcr.io/meltface-80/musicd-lms-remote:latest

🦆 Mallard for Android · v0.2.0

The native app: every screen of the web app, the lock screen and notification controls, a home-screen widget, and your phone as a Lyrion player of its own. A 64-bit phone with Android 8.0 or later. Installed, it offers each newer version itself.

⬇ Download Mallard

Release page · Android asks once to allow installing from your browser.

Test builds

What is coming next is published as it is merged, for anyone who wants to try it early and report what they find: the server as ghcr.io/meltface-80/musicd-lms-remote:dev (use :dev in place of :latest), and Mallard as mallard-test.apk. A test server says so in Settings → System; you update it by pulling :dev again. Test builds are never offered to anyone on a release.
